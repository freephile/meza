Meza command "debug"

DESCRIPTION:
	Debug Ansible variables and facts for the specified environment.
	General-purpose debug command that can output any Ansible variable or fact.

USAGE:
	meza debug <environment> [<variable>]

EXAMPLES:
	# Show list_of_wikis (default variable)
	meza debug monolith

	# Show specific variable
	meza debug monolith m_htdocs

	# Show all host variables
	meza debug monolith hostvars

	# Show all Ansible facts
	meza debug monolith ansible_facts

	# Show specific path variable
	meza debug production m_mediawiki

ARGUMENTS:
	<environment>    Environment name (required)
	<variable>       Variable name to debug (optional, defaults to 'list_of_wikis')

NOTES:
	This command runs the set-vars role to load all configuration and then
	outputs the specified variable using Ansible's debug module. Useful for
	troubleshooting configuration issues and examining any Ansible variable
	or fact available in the environment.

COMMON VARIABLES:
	list_of_wikis       - List of configured wikis
	m_htdocs           - Web document root path
	m_mediawiki        - MediaWiki installation path
	m_meza_data        - Meza data directory path
	hostvars           - All host variables
	ansible_facts      - All gathered facts
