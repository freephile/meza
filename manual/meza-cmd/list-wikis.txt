Meza command "list-wikis"

DESCRIPTION:
	List all wikis configured for the specified environment.
	Uses the general-purpose debug.yml playbook to display list_of_wikis.

USAGE:
	meza list-wikis [<environment>]

EXAMPLES:
	# List wikis for default environment (monolith)
	meza list-wikis

	# List wikis for specific environment
	meza list-wikis production

	# List wikis for development environment
	meza list-wikis dev

ARGUMENTS:
	<environment>    Environment name (optional, defaults to 'monolith')

NOTES:
	This command uses the general-purpose debug.yml playbook with the
	list_of_wikis variable. It shows all wikis from either the declarative
	wikis: section in public.yml or filesystem discovery.
	
	For debugging other variables, use: meza debug <env> <variable>
