Mediawiki EZ Admin

Usage: meza migrate-wikis [environment]

Migrate existing directory-based wikis to declarative configuration.

This command scans existing wiki directories in /opt/conf-meza/public/wikis/
and extracts wiki names from their base.php files to automatically populate
the wikis: section in public.yml.

Arguments:
    environment    Name of the environment to migrate (required)

Example:
    meza migrate-wikis production

The migration process:
1. Scans /opt/conf-meza/public/wikis/ for existing wiki directories
2. Reads each wiki's preLocalSettings.d/base.php to extract $wgSitename
3. Creates or updates public.yml with discovered wikis in declarative format
4. Makes the first wiki found primary (or 'demo' wiki if it exists)
5. Backs up any existing public.yml before making changes

After migration, your wikis will be managed declaratively and you can:
- Add new wikis by editing public.yml or using 'meza create wiki'  
- Remove wikis by editing public.yml or using 'meza delete wiki'
- Control wiki ordering and primary wiki designation
- Use wiki redirects and other advanced features

Note: This command only updates configuration. Run 'meza deploy' after
migration to apply the changes to your servers.
